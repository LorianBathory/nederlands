# Уже изучено

Этот файл содержит только материал, который пользователь прямо подтвердил как изученный. Перечисленные здесь сведения не включаются в будущие разборы, разделы повторения и итоговые списки A1+.

Изменять этот список можно только по прямому указанию пользователя.

## Глаголы

### zijn — быть

Настоящее время (`tegenwoordige tijd`):

| Лицо | Форма |
|---|---|
| ik | ben |
| jij / je | bent |
| u | bent / is |
| hij / zij / ze / het | is |
| wij / we | zijn |
| jullie | zijn |
| zij / ze | zijn |

### hebben — иметь

Настоящее время (`tegenwoordige tijd`):

| Лицо | Форма |
|---|---|
| ik | heb |
| jij / je | hebt |
| u | hebt / heeft |
| hij / zij / ze / het | heeft |
| wij / we | hebben |
| jullie | hebben |
| zij / ze | hebben |

## Глагольные конструкции и управление

- **willen + infinitief** — хотеть что-либо сделать. После **willen** используется инфинитив без **te**.

## Прилагательные

- **nieuw / nieuwe** — новый / новая / новое / новые.
- **lekker / lekkere** — вкусный; приятный, удобный или уютный в зависимости от контекста.

## Устойчивые сочетания

- **de hele wereld** — весь мир, весь свет.

## Существительные

- **de stoel — de stoelen** — стул, кресло.
- **het baasje — de baasjes** — хозяин домашнего животного; уменьшительная форма от **de baas — de bazen**.
- **de poes — de poezen** — кошка.
