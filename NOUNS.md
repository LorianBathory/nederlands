# Существительные

Этот справочник объединяет существительные из всех доступных разборов историй за 4–17 января. Повторяющиеся слова приведены один раз. У каждого слова указаны артикль, единственное и множественное число; для вещественных существительных также пояснено, в каком значении возможно множественное число.
