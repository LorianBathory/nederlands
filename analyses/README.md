# Разборы историй

В этой папке каждый разбор хранится в отдельном Markdown-файле. Разбор начинается с точной копии исходной истории и оформляется по шаблону и правилам из [`AGENTS.md`](../AGENTS.md).

Имя файла должно соответствовать полному заголовку истории, обязательно включать дату и записываться латиницей в `kebab-case`. Например, разбор истории `4 januari — De stoel van Bollie` хранится в файле `4-januari-de-stoel-van-bollie.md`.
